Install Everything

One command. All plugins.

Installs all available NMD plugins to your Claude Code setup. Takes 30 seconds. Run it after you have Claude Code installed.

# Install all NMD plugins at once:
curl -sSL https://raw.githubusercontent.com/nmdzaza/nmd-plugins/main/install.sh | bash
# Or install just what you need:
curl -sSL https://raw.githubusercontent.com/nmdzaza/nmd-plugins/main/install.sh | bash -s social
