# NMD Social Media Engine

One prompt → content for Instagram, Facebook, X (Twitter), LinkedIn, blog, and newsletter simultaneously. Built for NMD ZAZA's content operation across credit intelligence, car sales, real estate, and NMD Market.

## Platforms and Specs

| Platform | Format | Tone | Length | Hashtags |
|----------|--------|------|--------|----------|
| Instagram | Caption + image/video hook | Punchy, visual, motivational | 150–300 chars above fold | 5–10 niche tags |
| Facebook | Post + optional link | Conversational, story-driven | 100–500 chars | 2–3 tags max |
| X (Twitter) | Thread or single tweet | Direct, edgy, informative | 280 chars per tweet | 1–2 tags |
| LinkedIn | Article-style post | Professional, authoritative | 800–1,500 chars | None or 3 max |
| Blog (GitHub Pages / creditintelligence.com) | Full article | Detailed, SEO-optimized | 800–1,500 words | N/A |
| Newsletter | Email-format content | Personal, insider | 300–600 words | N/A |

## Cross-Post Workflow

When asked to cross-post content:

1. Identify the core message or story
2. Generate the full long-form version (blog/LinkedIn) first
3. Distill down to each shorter platform format
4. Adapt tone per platform (see specs above)
5. Write Higgsfield AI video hook if video content requested
6. Output all versions in a single response, clearly labeled by platform
7. Include hashtag set for Instagram and X

## Higgsfield AI Video Hook

Higgsfield generates AI video clips. Hook format for scripts:

- **Hook (0–3 sec)**: Disruptive visual or statement. "What if your phone could fix your credit?"
- **Problem (3–8 sec)**: Agitate the pain. "Most people don't know they have 30+ errors on their report."
- **Solution (8–15 sec)**: Show the tool/method. "Here's how I use AI to dispute them all in 5 minutes."
- **CTA (15–20 sec)**: Drive action. "Link in bio — get the AI Employee Blueprint."

When asked to write a video hook, output the full scene description + voiceover script in this format.
