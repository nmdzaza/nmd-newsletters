The Technology

Claude & AI Questions

Claude is the AI assistant made by Anthropic — one of the leading AI companies in the world. It's available as a free app (claude.ai) and as a downloadable desktop app. Claude is what powers our AI employees — think of it as the brain, and our skills are the job training.

Claude free gives you limited daily messages. Claude Pro (~$20/month) gives you extended usage, access to the most powerful models, and the ability to use Claude Code — which is required for running NMD's full AI employee suite. We always recommend Pro for professional use.

Claude Code is Anthropic's advanced agentic interface — it lets Claude take real actions on your computer, run automations, and use installed skills (like ours). It's the environment where NMD AI employees live and operate. You install it once, load our skills, and your AI team is ready to work.

Our tools are built as Claude skills — structured prompt files that install into Claude Code. We have submitted tools to Anthropic's official plugin marketplace and continue to build for the platform. All skills are built to Claude's standards and work natively inside the Claude Code environment.

Yes. Claude is built by Anthropic with strong privacy standards. Your conversations are not used to train the model by default (especially on Pro). Our skills run locally on your machine — your leads, client data, and business info stay on your device, not on NMD's servers.

Setup & Install

The full step-by-step guide is on our Get Started page. The short version:

  • Download Claude Code (free from Anthropic)
  • Copy the skill file we send you into your skills folder
  • Open Claude Code and the AI employee is ready to work
Most people are up and running in under 10 minutes.

Yes. Claude Code runs on Mac, Windows, and Linux. The installation steps are slightly different per OS — our Get Started guide walks through all three. Mobile-only users can use the web version of Claude with some limitations.

Try these steps first:

  • Make sure the skill file is in the correct folder: ~/.claude/skills/
  • Restart Claude Code after adding the file
  • Type the skill name exactly as shown in the instructions (e.g., /probate-hunter)
  • Make sure you're on Claude Pro — some skills require extended context
