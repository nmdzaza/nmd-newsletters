Setup Guide
From zero to running.

Every step. Exactly what I had to figure out.

1
Create a free Claude account
Go to claude.ai and sign up. A free account works for running plugins. No credit card required.
Go to Claude.ai →
Note
If you already have a Claude account, skip this step. Claude Pro ($20/mo) gives you higher usage limits which helps when running longer plugin sessions.
2
Install Node.js
Claude Code runs on Node.js. Download and install it first — this is a one-time setup.
Download Node.js →
How to check if Node is already installed
Open Terminal and type node --version — if you see a version number (like v20.x.x) you're good to go.
3
Open your Terminal
Terminal is where you'll install and run Claude Code. Here's how to open it on each system:
Mac
Windows
Linux
# Press Command + Space, type "Terminal", hit Enter
# OR go to Applications → Utilities → Terminal
# Press Windows key + R, type "cmd", hit Enter
# OR search "Command Prompt" in Start Menu
# PowerShell also works — search "PowerShell"
# Press Ctrl + Alt + T
# OR right-click desktop → "Open Terminal"
4
Install Claude Code
In your terminal, paste this command and hit Enter. It installs Claude Code globally on your machine.
$npm install -g @anthropic-ai/claude-code
# Wait for it to finish — takes about 30 seconds
If you see a permissions error on Mac
Try: sudo npm install -g @anthropic-ai/claude-code and enter your Mac password when it asks.
5
Start Claude Code
In your terminal, type claude and hit Enter. The first time it will ask you to log in with your Claude account.
$claude
# It will open a login link in your browser
# Log in with your Claude account from Step 1
# Come back to terminal when done
6
Install the NMD Plugin
Once Claude Code is running, type the install command for the plugin you want. Pick one:
# For Credit Repair:
>/plugin install credit-repair-pro@claude-plugin-directory

# For Car Sales Suite:
>/plugin install car-sales-suite@claude-plugin-directory

# For Newsletter Engine:
>/plugin install nmd-newsletters@claude-plugin-directory
Or browse the plugin directory
Type /plugin then select Discover to browse all available plugins and install from the menu.
7
Run setup & start using it
After installing, run the setup command. It walks you through saving your profile so the plugin knows your info every time.
# Credit Repair — enter your info once:
>/credit-setup

# Car Sales Suite — enter your dealership info:
>/dealer-onboarding

# Then run the main skill:
>/car-sales
That's it
From here Claude runs the tool. It can open your browser, pull data, write letters, and take real actions — not just give you text.
